How one message flows through it

A customer writes "how much for balayage?" tenants → found by slug · ai_employees → load compiled_prompt · customers → find/create by session · conversations → find open or create · hard blocks checked (opted_out? wallet ≤ 0? cost cap?) · AI answers · messages ×2 → both sides saved · ai_decision_log → 3 cost numbers · usage_ledger+tenants.wallet → debit, atomic
The AI books an appointment intent detected → items checked (bookable? duration?) → insert bookings. If the slot is taken, the UNIQUE index rejects it politely — no double booking, no lock code needed.
The AI hands over to a human trigger fires → insert escalations → conversations.status = 'escalated' → customer told a person will follow up. The model's own reply is NOT sent.
The owner edits a price items updated → compiler re-runs → save_compiled_prompt() → config_version +1 → next answer quotes the new price. The demo closer.
